# Приложение для поиска вакансий.
## Описание: 
Данный проект позволяет получать вакансии с сайта HeadHunter, сохранять их в JSON-файл, фильтровать по ключевым словам и зарплате. 
## Реализация:
1) BaseApi абстрактный класс для класса HeadHunterApi, в котором реализуется подключение к API hh.ru и получение списка вакансий по ключевому слову.
2) BaseSaverToJson абстрактный класс для класса SaveInfoToJson, в котором реализуется сохранение вакансий в JSON-файл, добавление новых вакансий, фильтрация по ключевым словам, удаление, очистка всего хранилища.
3) Класс Vacancies реализует валидацию по зарплате, сравнение вакансий по зарплате и сортировка.
4) В модуле utils находятся дополнительные вспомогательные функции 
## Тестирование:
Проект покрыт тестами. Для тестирования:
1) poetry add --group dev pytest pytest-cov 
2) pytest --cov=src --cov-report=html
3) pytest --cov
## Запуск проекта
Запуск проекта осуществляется через главный модуль main
